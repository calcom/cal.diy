# Famulor

[Famulor](https://www.famulor.io) AI voice assistants check availability, book, cancel and reschedule bookings on your Cal.diy event types during phone calls and chats.

## Installation

1. Install the Famulor app from the Cal.diy App Store. It opens the Famulor setup guide.
2. In Cal.diy, create an API key under `/settings/developer/api-keys`.
3. Sign in at [app.famulor.io](https://app.famulor.io), open **Booking → Integrations → Cal.com**, paste the API key and choose the **Custom** API endpoint with the public URL of your Cal.diy instance.
4. Select **Load event types**, choose the event type, save, and assign the integration to an assistant.

The Cal.diy instance must be reachable over public HTTPS. Localhost URLs cannot be used.
