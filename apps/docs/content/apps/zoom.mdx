# Zoom

### Obtaining Zoom Client ID and Secret

1. **Sign into Zoom Marketplace** - Go to [Zoom Marketplace](https://marketplace.zoom.us/) and sign in with your Zoom account.

2. **Build a New App** - In the upper right, click "Develop" and then select "Build App".

3. **Create a General App** - On the app type selection page, find the **General App** card and click "Create" (Zoom consolidated OAuth into General Apps).

4. **Name Your App** - Provide a name for your app.

5. **Choose User-managed App Type** - Under app type, select **User-managed** so users can authorize their individual Zoom accounts.

6. **Set Marketplace Visibility** - Keep the option to publish the app on the Zoom App Marketplace toggled off for internal, self-hosted use.

7. **Create the App** - Click "Create" to proceed to app configuration.

8. **Save Client ID and Secret** - Under **App Credentials**, copy the Client ID and Client Secret, then add them to your `.env` file:

```
ZOOM_CLIENT_ID=
ZOOM_CLIENT_SECRET=
```

9. **Set the Redirect URL for OAuth** - In the **OAuth** section, set the OAuth Redirect URL to:

```
<Cal.diy URL>/api/integrations/zoomvideo/callback
```

Replace `<Cal.diy URL>` with your application URL (e.g. `https://app.cal.diy` or `http://localhost:3000`).

10. **Configure OAuth Allow List and Strict Mode** - Add the redirect URL to the **OAuth Allow List**. Toggle on **"Use strict mode on redirect URLs"** (or enable Subdomain check if using subdomains). Ensure the status displays "Saved".

11. **Add Required Scopes** - Go to the **Scopes** tab and click **"+ Add Scopes"**. Select the **Meeting** category on the left, then check:
    - `meeting:write`
    - `meeting:read`

12. **Save the Scope** - Click "Done" to save your scope settings.

13. **Complete Zoom Integration** - Your Zoom integration is now ready and can be enabled in Cal.diy settings under **Settings → Integrations → Video**.
